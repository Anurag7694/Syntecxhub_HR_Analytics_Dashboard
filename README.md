 HR Analytics Dashboard

 📊 Project Overview

An interactive HR Analytics Dashboard developed using Microsoft Power BI
to analyze employee attrition, workforce distribution, salary,
experience, overtime, and job satisfaction.

 🎯 Objectives

- Analyze employee attrition patterns
- Compare attrition across departments
- Analyze workforce distribution by job level
- Study salary and experience relationships
- Analyze overtime and attrition
- Analyze job satisfaction and attrition rate
- Provide interactive HR insights

 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- CSV Dataset

 📈 Dashboard Features

- Total Employees
- Total Attrition
- Attrition Rate
- Average Salary
- Average Experience
- Department-wise Attrition
- Job Level Distribution
- Overtime & Attrition Analysis
- Salary vs Experience Analysis
- Job Satisfaction vs Attrition Rate
- Interactive Department, Job Level and Overtime slicers

 📂 Dataset

The project uses an HR employee dataset containing information
about employee demographics, department, job role, salary,
experience, satisfaction, overtime and attrition.
